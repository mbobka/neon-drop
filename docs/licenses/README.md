# Сторонние ресурсы

`OpenSans-Regular.ttf` и `OpenSans-Semibold.ttf` взяты из шаблона .NET MAUI. Метаданные поставляемых файлов: Open Sans 1.10, Digitized data copyright © 2010–2011, Google Corporation. Лицензия: Apache License 2.0, полный текст в `OpenSans-Apache-2.0.txt`.

Иллюстрации `aurora.png` и `hero.png` созданы для этого проекта встроенным imagegen. Промпты находятся в `../artwork.md`.

Список библиотек и точные версии доступны в `.csproj`; их лицензии остаются у соответствующих правообладателей.
