# Графика Neon Drop

Две иллюстрации созданы встроенным **imagegen**, затем скопированы в ресурсы MAUI. Рисунки используются в самой игре, не только в документации. Игровые блоки рисуются C# / MAUI Graphics, чтобы сохранять чёткость при любом размере поля. Иконка и заставка — отдельные SVG.

## Фон

Файл: `src/NeonTetris/Resources/Images/aurora.png`.

Промпт:

> Use case: stylized-concept. Asset type: portrait background illustration for a premium Tetris-style Android game called Neon Drop. Create a beautiful atmospheric midnight indigo cosmic sky, subtle luminous cyan and violet aurora sweeping gently across upper third, tiny sparse stars, a few elegant floating translucent glass tetromino sculptures around the FAR outer edges, subtle peach and turquoise glow. Main center 65 percent should be very dark quiet negative space so a game board can sit over it with excellent contrast. Sophisticated matte grain, polished editorial videogame key art, depth, restrained bloom, not a screenshot or UI mockup. Full bleed vertical 2:3 composition. No text, no letters, no watermark, no borders.

## Стартовая иллюстрация

Файл: `src/NeonTetris/Resources/Images/hero.png`.

Промпт:

> Use case: stylized-concept. Asset type: landscape hero artwork for a premium colorful falling-block puzzle mobile game start panel. A small sculptural stack of polished translucent tetromino blocks floating above an obsidian pedestal in deep midnight indigo space, turquoise mint, lavender, peach and warm yellow glass, soft luminous edges, elegant high end 3D illustration, tasteful dark background, composition centered with all blocks fully in frame, no text, no letters, no watermark, no UI. Wide 3:2 composition.
