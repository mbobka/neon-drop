## Проверка интерфейса

| Сценарий | Результат |
| --- | --- |
| Pixel 7 AVD, Android 15, 1080×2400 / 420 dpi | Запуск, сенсорные кнопки, перемещение, сброс, резерв, пауза — работают. |
| Клавиатура эмулятора | Enter, стрелки, Space, C, P доставляются в игру; подтверждено Android logcat и изменением счёта/резерва. |
| Убийство процесса и холодный запуск | JSON снимка до/после совпадает; восстановлены счёт, 20 занятых клеток и пауза. |
| Pixel Fold AVD, Android 15, 2208×1840 / 420 dpi | Запуск на широком внутреннем экране, квадратные клетки, поле отдельно от управления. |
| Горизонтальная ориентация телефона | Поле слева, управление справа; партия сохраняется, поворот включает паузу. |
| Pixel Fold, HALF_OPENED / book | Получен реальный callback AndroidX, после JNI-преобразования распознана одна разделяющая область; поле целиком слева от сгиба. |
| Pixel Fold, HALF_OPENED / tabletop | При повороте граница сгиба стала горизонтальной; поле сверху, кнопки снизу, без пересечения шарнира. |
| Pixel Fold, CLOSED / внешний экран 1080×2092 | Приложение перешло на внешний экран, включило паузу и сохранило активную фигуру; устаревший сгиб очищен. |

У AVD `NeonDrop_Fold_API35` доступен датчик `hinge-angle0` и состояния `CLOSED=0`, `HALF_OPENED=1`, `OPENED=2`. AndroidX сообщает `HardwareFoldingFeature`, в том числе разделяющую линию `[1104,0,1104,1840]` при HALF_OPENED.

Физические телефоны/планшеты, OEM-внешние экраны, iOS и Windows target не тестировались. Приложение собирается именно для Android. Эмулятор не подтверждает особенности прошивок всех моделей из обзора.
