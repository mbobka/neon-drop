### Складные панели на macOS

Без Android Studio AVD Pixel Fold создан вручную: каталог `~/.android/avd/Fold_API35.avd/config.ini` скопирован с Pixel 8 и дополнен профилем складного экрана (`hw.lcd.width=2208`, `hw.lcd.height=1840`, `hw.sensor.hinge=yes`, `hw.sensor.hinge.areas=1104-0-0-1840`, `hw.sensor.hinge.type=1`, `hw.sensor.hinge.ranges=0-180`, `hw.sensor.posture_list=1, 2, 3`, `hw.sensor.hinge_angles_posture_definitions=0-30, 30-150, 150-180`, внешний экран `hw.displayRegion.0.1.*` 1080×2092 и `hw.sensor.hinge.fold_to_displayRegion.0.1_at_posture=1`, `PlayStore.enabled=false`). Эмулятор запускается как `emulator -avd Fold_API35 -no-snapshot`; `cmd device_state print-states` показывает `CLOSED=0`, `HALF_OPENED=1`, `OPENED=2`.

Особенности прогона: поза меняется через `adb emu sensor set hinge-angle0 180|90|0`; `settings put system user_rotation` эмулятор перебивает автоповоротом, работает `adb shell cmd window user-rotation lock 1` (и `lock 0` для возврата); у складного AVD два дисплея, поэтому `screencap` нужен с `-d <id>` из `dumpsys SurfaceFlinger --display-id`.
