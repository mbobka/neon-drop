# NeonTetris.Core

Независимый от UI движок, `net10.0`, без внешних зависимостей. Все публичные типы находятся в `NeonTetris.Core`.

```csharp
var game = new GameEngine(seed: 42);
game.Start();
game.Tick(TimeSpan.FromMilliseconds(16));
game.Move(-1);
game.Rotate();
var save = game.SerializeSnapshot();
game.RestoreSnapshot(save);
```

## Контракт для UI

- `Tetromino`: `I, O, T, S, Z, J, L` (значения 0–6).
- `Cell(int X, int Y)` и `ActivePiece(Tetromino Kind, int Rotation, int X, int Y)` — неизменяемые записи.
- `GameEngine(int? seed = null)`; `const int Width = 10`, `Height = 20`.
- `int[,] Board` индексируется `[x, y]`, содержит только зафиксированные клетки: 0 — пусто, `(int)kind + 1` — цвет фигуры. Ссылка на массив сохраняется при старте и восстановлении; UI должен только читать его.
- `ActivePiece? Active`, `ActivePiece? Ghost`; `IEnumerable<Cell> GetCells(ActivePiece piece)` возвращает абсолютные координаты четырёх клеток. При отображении пропускайте `Y < 0`. Сетка SRS: 3×3 для JLSTZ, 4×4 для I; вращения 0, 1, 2, 3 означают 0°, 90°, 180°, 270° по часовой стрелке. O сохраняет занимаемые клетки.
- `IReadOnlyList<Tetromino> Next` — следующие пять фигур, первая появится следующей. До старта список пуст. После изменения очереди читайте свойство заново.
- `Tetromino? Held`; `bool IsPaused`, `IsGameOver`, `IsStarted`; `int Score`, `Lines`, `Level`.
- Все команды возвращают `void`: `Start()`, `TogglePause()`, `Move(int dx)`, `Rotate(int direction = 1)`, `SoftDrop()`, `HardDrop()`, `Hold()`, `Tick(TimeSpan elapsed)`.
- `Move` проходит до `abs(dx)` столбцов и останавливается перед препятствием. Знак `direction` задаёт поворот на 90°, ноль ничего не делает.
- До старта, на паузе и после проигрыша команды движения не действуют. `Start()` полностью перезапускает игру с исходным seed. Отрицательный `elapsed` вызывает `ArgumentOutOfRangeException`.
- Вызывайте команды и считывайте состояние в одном потоке. Событий и `INotifyPropertyChanged` нет: UI обновляется после команды или `Tick`. Передавайте время с прошлого кадра; пауза не накапливает долг падения.

## Правила

Перемешивание 7-bag, SRS с отдельными смещениями для I, hold один раз до фиксации текущей фигуры, проекция приземления. Фигура появляется в `(3, -1)`. Столкновение при появлении или фиксация с клетками выше поля заканчивает игру; `Active` и `Ghost` становятся `null`.

Уровень начинается с 1 и повышается каждые 10 строк. Интервал гравитации: `max(50, 1000 * 0.8^(Level - 1))` мс. Задержка фиксации — 500 мс контакта с поверхностью. Успешный сдвиг или поворот фигуры, стоящей на поверхности, сбрасывает задержку не более 15 раз за фигуру. В воздухе таймер фиксации приостанавливается. Hard drop фиксирует сразу.

За 1/2/3/4 одновременно удалённые строки: 100/300/500/800 × уровень до удаления. Soft drop даёт 1 очко за клетку, hard drop — 2. Автоматическое падение очков не даёт. Бонусы за T-spin, combo и back-to-back не предусмотрены. Счёт насыщается на `int.MaxValue`.

## Сохранение

`string SerializeSnapshot()` и `void RestoreSnapshot(string json)` сохраняют поле, активную фигуру, полную очередь, hold и его ограничение, очки, флаги, таймеры, число сбросов фиксации и состояние генератора. Загрузка не включает паузу автоматически. Снимок версии 1 хранит поле построчно (`y * Width + x`). Неверный JSON, неподдерживаемая версия или некорректное состояние вызывают `ArgumentException`, оставляя текущую игру без изменений. Рассматривайте JSON как непрозрачный формат сохранения.

Сериализация использует source-generated `JsonSerializerContext` и перегрузки с `JsonTypeInfo`: reflection не требуется, в том числе при trimming/AOT. После перезапуска процесса создайте `GameEngine` и вызовите `RestoreSnapshot(json)` **без** последующего `Start()`. Хранение строки в Preferences или файле и вызов сохранения при событиях жизненного цикла принадлежат UI.
